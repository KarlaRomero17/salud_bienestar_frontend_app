Salud Bienestar Frontend

Aplicación móvil de salud y bienestar, construida con React Native (Expo SDK 53).
Incluye autenticación de usuarios, navegación profesional y arquitectura modular.

📁 Estructura del proyecto
salud_bienestar_frontend_app/
├── App.js                     # Punto de entrada de la app
├── index.js                   # Registro de la app
├── src/
│   ├── components/            # Componentes reutilizables (Botones, Inputs, Cards)
│   ├── screens/               # Pantallas principales (Login, Home, Dashboard)
│   ├── navigation/            # React Navigation (AppNavigation.js)
│   ├── context/               # Context API (AuthContext)
│   ├── services/              # Lógica de negocio / llamadas a API
│   ├── api/                   # Configuración de Axios (apiClient.js)
│   └── assets/                # Imágenes, íconos, fuentes
├── package.json               # Dependencias y scripts
└── README.md                  # Documentación del proyecto

🚀 Tecnología
- React Native / Expo SDK 53
- React Navigation
- Axios

# Instalación
1. Clona el repositorio:
    git clone

2. Abre la carpeta del proyecto:
    cd salud_bienestar_frontend_app

3. Instala las dependencias:
    npm install

4. Inicia la app:
    npm start
    (o usa Expo Go en tu dispositivo móvil)
